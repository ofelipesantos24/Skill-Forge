Documentação

Como o Skill Forge funciona e como escrever um SKILL.md que o agente realmente vai usar corretamente.

O que é um SKILL.md

É um arquivo de metadados + instruções que ensina um agente (como o Claude Code) a reconhecer quando uma tarefa se encaixa em uma "skill" específica e como executá-la. Ele fica geralmente em uma pasta própria, por exemplo:

minha-skill/
  SKILL.md
  scripts/
  examples/

Campos do gerador

CampoPara que serve
nameIdentificador único da skill (slug). Usado internamente pelo agente e por marketplaces de skills.
descriptionO campo mais importante. É o que o agente lê para decidir se deve carregar essa skill. Deve conter gatilhos claros — frases, palavras-chave ou tipos de arquivo que indicam que a skill se aplica.
categoryAjuda humanos (e marketplaces) a organizar e descobrir a skill.
licenseRelevante se você for publicar a skill publicamente.
stepsSequência que o agente deve seguir ao executar a skill — vira uma lista numerada no corpo do documento.
notesRestrições explícitas — coisas que a skill nunca deve fazer, mesmo se parecer razoável no contexto.

Boas práticas para o campo "descrição"

Regra de ouro: a descrição é o que decide se a skill dispara ou não. Uma descrição vaga ("ajuda com documentos") faz a skill nunca disparar ou disparar demais.
  • Inclua exemplos concretos de pedidos do usuário que devem ativar a skill.
  • Mencione extensões de arquivo, nomes de ferramentas ou palavras-chave específicas, quando fizer sentido.
  • Diga também quando não usar a skill, se houver ambiguidade com outra skill parecida.

Exemplo de boa descrição

Use esta skill sempre que o usuário pedir para gerar um relatório
mensal de vendas em PDF a partir de uma planilha CSV ou XLSX.
Gatilhos: "relatório mensal", "fechamento do mês", arquivos .csv/.xlsx
anexados junto com um pedido de resumo. Não usar para relatórios
anuais (ver skill "relatorio-anual").

Estrutura recomendada do repositório

Ao publicar sua skill (por exemplo em um marketplace de plugins do Claude Code), mantenha uma pasta por skill, com o SKILL.md na raiz dela e scripts auxiliares em scripts/. Isso segue o mesmo padrão usado por projetos como obra/superpowers.

Usando o gerador

Abra gerador.html, preencha os campos à esquerda e o SKILL.md aparece pronto à direita, atualizado em tempo real. Use o botão Copiar e cole em um arquivo SKILL.md na pasta da sua skill.

Este site é 100% estático — nenhum campo que você preenche é enviado para fora do navegador.
